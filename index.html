See how your model really flows

Drop one or more Anaplan line item blueprint exports here. The file is read by this page only and never leaves your device.

  1. In Anaplan, open Modules and go to the Line Items tab (or a module's Blueprint view).
  2. Select all rows and export as CSV. Keep the Module, Line Item, Format, Formula and Applies To columns.
  3. Drag the file here or use Load CSV export.

That's too many to draw at once. Search for a line item to see its lineage, or open a module.
